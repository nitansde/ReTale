# ReTale 默认 · 中文

这套预设面向无需调节开关的中文小说创作，适用于改写、扩写、续写、Future Jump 和角色互动。参考「夏瑾 双鱼座 Beta 0.40」的人物驱动、对白自然、视角有限和情节连贯思路，重新编写为六条独立、默认启用的规则。

文件沿用 SillyTavern 的 Chat Completion 预设 JSON 格式：`prompts`、`prompt_order`、`identifier`、`role`、`system_prompt`、`marker` 和注入位置等字段均保留。六条写作规则以外，另有八个原生上下文占位条目，承接世界书、用户设定、角色描述与性格、场景、对话示例和聊天记录；它们没有额外提示词，也无需用户调整。`main` 保留为主提示槽，自定义规则明确标记 `system_prompt: false`，同时提供 `100000` 和 `100001` 两套标准顺序。

“安静”指减少预设对故事的额外干预；“清爽”指表达准确、交付直接。原作的幽默、紧张、冲突与浓烈情感仍随场景保留，不把不同题材统一成清淡文风。

| 条目 | 默认行为 |
| --- | --- |
| 任务理解 | 分清改写、扩写、续写和互动，具体请求优先于通用偏好。 |
| 设定与视角 | 保持故事连续性，区分角色认知，不提前使用未来事实。 |
| 人物与对白 | 由性格和处境驱动反应，台词有回应，情绪变化有依据。 |
| 清爽表达 | 跟随原文，细节有取舍，减少套话、解释和比喻堆叠。 |
| 自然推进 | 每轮有所进展，节奏随场景变化，结尾自然停顿。 |
| 篇幅与交付 | 按本次篇幅和格式要求交付，默认不附带额外说明或面板。 |

不携带互斥文风开关、特定题材强化、固定角色身份、宏变量、思考输出模板、额外标签或正文删改正则。不强制字数下限，也不接管温度、采样、上下文、输出上限或流式设置；这些参数由应用和所选模型配置决定。

## 使用与维护

- 新预设库自动选择此预设用于三个创作入口，分析与检索入口保持关闭。
- 已有预设库自动补入一次，保留原有预设、绑定、书籍选择与系统提示词。可在预设选择器中选择「ReTale 默认 · 中文」。
- 用户编辑或删除此预设后，保存并重载不会覆盖编辑或重新添加已删除的预设。
- 六条规则作为用户侧写作偏好加入上下文，保留各创作入口的原生系统提示和格式约束，包括角色扮演的 JSON blocks。
- SillyTavern 根据占位条目填入其原生上下文；ReTale 保留这些条目用于导入导出，由自身创作入口提供上下文，不将空占位条目作为错误提示。
- 单一内容源是 [`config/presets/retale-default-zh-CN.json`](../config/presets/retale-default-zh-CN.json)，也可通过现有 JSON 预设导入功能使用；编辑器仍支持修改和导出。

## 检查重点

除了预设的导入、保存、导出与运行时组装检查，模型效果可用日常对话、紧张冲突、指定分歧改写和角色互动四类片段观察：是否贴合原作、推进适量、人物反应有依据，且没有多余说明。结构测试只能验证预设正确生效，不能代替具体模型的文风评估。
